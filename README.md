# releaseguard-site

Public product website for ReleaseGuard, served by GitHub Pages at https://releaseguard.code-it.info.

Plain static HTML and one stylesheet — no build step, no scripts, no external fonts, cookies or trackers.

| File | Page |
|---|---|
| `index.html` | Product overview |
| `pricing.html` | Plans and trial |
| `support.html` | Contact and response times |
| `privacy.html` | Privacy policy (linked from the AppExchange listing) |
| `terms.html` | Terms of use / licence (linked from the AppExchange listing) |

The header and footer are repeated in every page; change them in all five files.
Prices and support levels must match `.claude/docs/pricing-and-gtm.md` in the ReleaseGuard repository.

Preview locally: open `index.html` in a browser.
Work is tracked in lukWaszkiewicz/ReleaseGuard#108.
